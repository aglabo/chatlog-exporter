# chatlog-exporter

AI エージェントのチャットログをエクスポート、分類、整理するためのツール群です。

chatlog-exporter は、AI コーディングエージェントのセッション履歴を構造化された Markdown ファイルに変換し、レビュー、フィルタリング、Obsidian などのナレッジベースへの取り込みをしやすくします。

使い方、セットアップ、詳細なドキュメントは GitHub Pages を参照してください。
