# 命名規則（プロジェクト固有）

## 関数内ローカル変数（追加ガイダンス）

グローバル規則の「主要変数」に加え、このプロジェクトでは以下も `_` プレフィックスを付ける。

- AI/CLI 実行の入出力（`_cmd`, `_process`, `_writer`, `_output`, `_raw`）
- ドメイン概念を表す変数（`_agentDir`, `_slug`, `_systemPrompt`）

## 一時補助変数（プロジェクト慣例）

以下はこのプロジェクトで頻出するイテレーション変数であり `_` 不要。

- `entry`, `line`, `arg`, `turn`, `segment`（`for...of` イテレーション変数）
- コールバック引数（`turns.filter((t) => ...)` の `t`）

注: 関数パラメータ自体には `_` を付けない（TypeScript の「未使用引数」慣習とは別）。
