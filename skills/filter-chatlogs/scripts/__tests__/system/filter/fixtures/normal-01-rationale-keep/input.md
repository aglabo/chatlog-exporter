---
title: 定例ミーティングの曜日を変えるか
category: misc
---

### User

うちのチームの定例ミーティング、いまは毎週火曜の朝なんですが、木曜に動かすかどうか迷っています。金曜にする案もあります。相談に乗ってください。

### Assistant

いまの火曜で困っていることと、動かせない予定があるかを教えてください。

### User

困っているのは、月曜が祝日の週です。火曜が実質その週の初日になるので、当日の朝までに共有する資料がまだ誰も書けていない状態で集まることになって、雑談で終わってしまいます。祝日は年に何回かある程度ですが、そのたびに 1 回まるまる無駄になっています。

動かせない予定としては、毎月末の締め作業が金曜に固まっています。あとは特にありません。

### Assistant

金曜案は外したほうがよいと思います。理由は、いま挙げてもらった月末の締め作業と重なるからです。月末が金曜に当たる週は締め作業を優先することになるので、その週は定例が飛びます。月に 1 回は飛ぶ前提の曜日を選ぶと、飛んだ週の連絡をどこでするかという別の手当てが必要になり、面倒が増えます。

木曜案を勧めます。前半に 2 営業日あるので、月曜が祝日の週でも資料を書く時間が残ります。締め作業ともぶつかりません。

ひとつ前提を書き留めておくとよいです。この判断は「資料は当日の朝までに各自が書く」という今のやり方が続くことを前提にしています。もし資料を前の週のうちに用意する運用に変えるなら、火曜のままでも困らなくなるので、この結論は見直してください。

### User

たしかに月末が金曜なのは毎月ですね。ではその方針で確定します。定例は木曜の朝に移します。

### Assistant

承知しました。移す理由（月曜祝日の週に資料が間に合わない、金曜は月末の締め作業と重なる）を、カレンダーの定例予定の備考欄に 1 行だけ残しておくことをお勧めします。数か月後に「なぜ火曜をやめたのか」を誰かが聞いたときに、そこを見れば済みます。
