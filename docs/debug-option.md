# デバッグオプション (`--debug`)

AI を呼び出すスキル（classify / filter / normalize / set-frontmatter）は、`--debug` で AI 診断ログを stderr に出力する。

## 有効にする方法

優先順位は **CLI 引数 > `config.yaml` > 既定値 (`false`)**。

| 指定方法                       | 効果                                 |
| ------------------------------ | ------------------------------------ |
| `--debug`                      | 有効にする                           |
| `--no-debug`                   | 無効にする（`config.yaml` を上書き） |
| `config.yaml` の `debug: true` | CLI で指定しなければ有効にする       |

## 出力する内容

| 項目                 | 内容                                                             |
| -------------------- | ---------------------------------------------------------------- |
| タイミング・リトライ | AI リクエストの所要時間、DNS リトライの試行回数と待ち時間        |
| `max_tokens`         | AI に送信した max_tokens                                         |
| `usage`              | 応答の usage 全体                                                |
| `finish_reason`      | 応答の finish_reason                                             |
| 応答本文の末尾       | 応答本文の末尾 500 文字                                          |
| エラー全文           | AI 呼び出しが失敗したときの `message` 全文（CLI 出力を含みうる） |

debug が無効のときは、AI 失敗の警告にエラーの分類（`kind/subindex` またはエラー名）だけを添える。

## 注意

**メタデータのみのログではない。** プロンプトは出さないが、応答本文の一部とエラー全文を出力する。
応答本文やエラーにはチャットログの内容が含まれうるため、stderr を保存・共有する環境（CI ログ等）では有効にしない。
