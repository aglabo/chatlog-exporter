## 概要

`.config/chatlog-exporter/config.yaml` は、すべてのスキルが読むグローバル設定です。
既定のエージェント、AI モデル、タイムアウト、バッチサイズ、フィルタの閾値、ディレクトリの場所を定めます。
`/setup-chatlogs` で配置され、直接編集すると以降のすべての実行の既定値が変わります。

辞書や AI プロンプトのカスタマイズは、[辞書のカスタマイズ](./dictionaries) と [プロンプトのカスタマイズ](./prompts) を参照してください。

## 読み込みの仕組み

- **場所**: **カレントディレクトリ**からの相対で `.config/chatlog-exporter/config.yaml` を読みます。
  `/setup-chatlogs` を実行したディレクトリでスキルを実行してください。
  ホームディレクトリや親ディレクトリは探しません。
- **別のファイル**: `--config FILE` (全スキル共通) で別のファイルを読めます。
  絶対パスはそのまま使います。相対パスは `.config/chatlog-exporter/` 配下として解決するため、
  `--config my.yaml` は `.config/chatlog-exporter/my.yaml` を読みます。
- **ファイルが無い場合**: 既定の `config.yaml` が無ければ組み込みの既定値で動きます。
  `--config` で指定したファイルが無い場合はエラーで停止します。
- **キーが無い場合**: 書かなかったキーは、組み込みの既定値になります。
  変更したいキーだけを書けば足ります。
- **値が空の場合**: 数値・真偽値のキー (例: `timeoutMs:`) は、空にしても既定値になります。
  文字列のキー (例: `agent:`・`model:`・`dicsDir:`) は既定値に**なりません**。空文字列として読まれます。
  文字列のキーを既定値に戻すときは、その行ごと削除してください。

値は次の順で決まります。

1. コマンドラインのオプション (オプションがあるスキルのみ)
2. `config.yaml` のキー
3. 組み込みの既定値

:::warning
**不正な値は実行を止めます**

- **未知のキー** (綴り間違いを含む) はエラーです。処理を始める前に停止します。
- **範囲外の数値** (下表の「範囲」) はエラーです。
- YAML の構文エラーはエラーです。

:::

## キー一覧

「既定値」はキーが無いときに使われる組み込みの値です。
配布版の `config.yaml` が異なる値を設定している場合は「配布版」に示します。

### エージェントと AI

| キー            | 既定値   | 配布版   | 範囲      | 説明                                                                                                                                       |
| --------------- | -------- | -------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `agent`         | `claude` |          | —         | コマンドラインでエージェントを指定しなかったときに処理するログ: `claude`・`codex`・`chatgpt`。                                             |
| `model`         | `sonnet` |          | —         | AI を呼ぶスキルが使うバックエンドとモデル。`--model` で上書きできます。書き方は [`--model` オプション](../reference/model-option) を参照。 |
| `timeoutMs`     | `120000` | `300000` | 0〜600000 | AI 呼び出し 1 回の制限時間 (ミリ秒)。`0` で無効。プロンプト評価だけで数分かかる低速なローカルモデルでは増やします。                        |
| `maxRetry`      | `2`      |          | 0〜10     | AI の応答を解析できなかったときに問い直す回数 (filter-chatlogs・set-frontmatter)。CLI やバックエンドのエラーは再試行しません。             |
| `debug`         | `false`  |          | —         | `true` で、応答本文の一部を含む AI の診断ログを stderr に出します。`--debug` と同じです。                                                  |
| `llamaEndpoint` | `''`     | (例)     | —         | `llama/<model>` が使う llama サーバの URL。ここでしか指定できません。配布版の値はサンプルなので、自分のサーバの URL に置き換えます。       |

### バッチと並列

| キー            | 既定値  | 配布版 | 範囲       | 説明                                                                                                                                     |
| --------------- | ------- | ------ | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `chunkSize`     | `10`    | `2`    | 1〜10      | filter-chatlogs と classify-chatlogs が 1 回の AI 呼び出しにまとめるファイル数。大きいほど呼び出し回数は減り、プロンプトは長くなります。 |
| `concurrency`   | `4`     |        | 1〜10      | 並列に実行する AI 呼び出しの数。`llama/<model>` では、サーバのスロット数 (`--parallel`) 以下にします。                                   |
| `batchSize`     | `4`     |        | 1〜10      | normalize-chatlogs がセグメント分割で 1 回の AI 呼び出しにまとめるファイル数。`--batch-size` で上書き。配布版には無いキーです。          |
| `maxBatchChars` | `20000` |        | 0〜1000000 | normalize-chatlogs の 1 回の呼び出しに含める本文の合計文字数の上限。`0` で無制限。`--max-batch-chars` で上書き。配布版には無いキーです。 |

### フィルタと文字数

| キー                | 既定値 | 配布版  | 範囲      | 説明                                                                                                                           |
| ------------------- | ------ | ------- | --------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `minCharCount`      | `1000` |         | 0〜100000 | filter-chatlogs: 本文がこれより短いログは、AI を呼ばずに削除します。                                                           |
| `minAssistantChars` | `300`  |         | 0〜100000 | filter-chatlogs: ユーザー発言が 1 回だけのログで、アシスタント応答に求める最小文字数。満たないログは AI を呼ばずに削除します。 |
| `maxBodyChars`      | `8000` |         | 1〜100000 | filter-chatlogs: 判定プロンプトに入れる各ログの本文の文字数。`0` は指定できません。`--max-body-chars` で上書き。               |
| `discardThreshold`  | `0.7`  |         | 0〜1      | filter-chatlogs: AI の確信度がこの値以上のときだけ DISCARD を適用します。上げると削除が減ります。                              |
| `maxContentLength`  | `4000` | `10000` | 0〜100000 | set-frontmatter: AI に送る前に本文をこの文字数で切り詰めます。                                                                 |

### ディレクトリ

| キー          | 既定値                                       | 説明                                                                                                        |
| ------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `chatlogsDir` | `./chatlogs`                                 | エクスポート・処理したログの基準ディレクトリ (`originalLogs/`・`normalizeLogs/`・`outputLogs/` の親)。      |
| `dicsDir`     | `dics`                                       | 辞書ディレクトリ。相対パスは `.config/chatlog-exporter/` 配下として解決します。                             |
| `projectsDic` | `.config/chatlog-exporter/dics/projects.dic` | classify-chatlogs が使うプロジェクト辞書。既定のままなら `dicsDir` に従います。                             |
| `promptsDir`  | `prompts`                                    | set-frontmatter が使うプロンプトディレクトリ。相対パスは `.config/chatlog-exporter/` 配下として解決します。 |
| `cacheDir`    | `${TEMP}/cle-cache`                          | AI の判定結果を保存するキャッシュのルート。                                                                 |

### 使われていないキー

`hashLength`・`minRandomLength`・`maxRandomLength` は互換性のために受け付けますが、
現在どのスキルも読みません。変更しても効果はありません。

## パス中の変数

パスの値には次の変数を書けます。

| 変数             | 展開される値                                              |
| ---------------- | --------------------------------------------------------- |
| `${ProjectRoot}` | スキル起動時のカレントディレクトリ (git のルートではない) |
| `${HOME}`        | `HOME`。未設定なら `USERPROFILE`                          |
| `${TEMP}`        | 環境変数 `TEMP`                                           |
| `${TMP}`         | 環境変数 `TMP`                                            |

これ以外の `${...}` はエラーです。許可された変数でも、未設定ならエラーになります。
展開後に `..` が残るパスも拒否されます。

## 設定例

Codex のログを既定にし、低速なローカルモデルに時間を与え、判断の際どいログを多めに残す例です。

```yaml
agent: codex
model: "llama/qwen3"
llamaEndpoint: "http://localhost:8080/"
timeoutMs: 600_000
concurrency: 2
discardThreshold: 0.85
```

:::warning
`/setup-chatlogs --force` は配布版の `.config/chatlog-exporter/` を既存のものに上書きコピーするため、
編集した `config.yaml` は置き換わります。実行前に控えを取るか、コミットしておいてください。
:::
