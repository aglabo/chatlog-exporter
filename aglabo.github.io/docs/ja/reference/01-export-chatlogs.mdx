## 概要

`/export-chatlogs` は、AIエージェントが手元のマシンに保存しているセッション履歴を読み込み、
セッションごとに Markdown ファイルとして書き出します。実質的な会話だけを残し、周囲のノイズは除外します。

[基本ワークフロー](../user-guide/basic-workflow) の最初のステップとして、新しいセッションをチャットログに取り込みたいときに使います。
AI を呼び出さないため、トークンは消費しません。

次のものは出力から除外されます。

- システムログや注入されたコンテンツ (`AGENTS.md`、パーミッション設定など)
- ツール使用・ツール結果のエントリ
- `/clear`、`/help`、`/exit` などのスラッシュコマンド
- `<system-reminder` などのシステムタグで始まるメッセージ
- `[Request interrupted`、`Tool loaded.` などの定型メッセージ
- `y`、`はい`、`ok` など、20 文字以下の短い肯定応答
- コミットメッセージ生成で始まるセッション (セッションごと除外)

## 使い方

```bash
/export-chatlogs [agent] [YYYY-MM] [オプション]
```

### 引数

| 引数      | 説明                                                                                                                  |
| --------- | --------------------------------------------------------------------------------------------------------------------- |
| `agent`   | エクスポートするエージェント: `claude`、`codex`、`chatgpt`。省略時は `config.yaml` の `agent` (未設定なら `claude`)。 |
| `YYYY-MM` | エクスポートする月。省略すると全期間が対象です。`agent` の後ろに置きます。                                            |

### オプション

| オプション         | 説明                                                                     |
| ------------------ | ------------------------------------------------------------------------ |
| `--input-dir DIR`  | 履歴の読み込み元。意味はエージェントによって異なります (下記参照)。      |
| `--export-dir DIR` | 既定の `chatlogs/originalLogs/` ではなく、`DIR` にそのまま書き出します。 |
| `--config FILE`    | 別の `config.yaml` を使います。                                          |

`--input-dir` の意味はエージェントごとに次のとおりです。

- `claude`: Claude のプロジェクトルート (既定 `~/.claude/projects`) を上書きします
- `chatgpt`: ChatGPT のデータエクスポートを展開したディレクトリ。`chatgpt` では**必須**です
- `codex`: 無視されます

:::warning

- 期間は `YYYY-MM` 形式のみ受け付けます。年だけ (`2026`) や、エージェントを付けない期間
  (`/export-chatlogs 2026-06`) はエラーになります。
- このスキルの `--dry-run` は未実装です。受け付けはしますが無視され、ファイルは通常どおり書き出されます。

:::

## 入力と出力

各エージェントの履歴は次の場所から読み込みます。

| エージェント | 読み込み元                                                    |
| ------------ | ------------------------------------------------------------- |
| `claude`     | `~/.claude/projects/<project>/*.jsonl` (`subagents/` は除く)  |
| `codex`      | `~/.codex/sessions/` 配下を再帰的に探索した `*.jsonl`         |
| `chatgpt`    | `--input-dir` で指定したディレクトリの `conversations-*.json` |

ファイルは `chatlogs/originalLogs/` 配下に、1 セッション 1 ファイルで書き出されます。

<FileTree>

- chatlogs/
  - originalLogs/
    - claude/
      - 2026/
        - 2026-06/
          - 2026-06-12-fix-encoding-a1b2c3d4e5f6.md

</FileTree>

ファイル名は `YYYY-MM-DD-<slug>-<id>.md` で、`<id>` はセッション ID から生成されます。
この段階ではプロジェクト別のサブディレクトリは作られません。
プロジェクト別の振り分けは、後工程の [`/classify-chatlogs`](./classify-chatlogs) が行います。

基準ディレクトリ `chatlogs/` は `config.yaml` の `chatlogsDir` で決まります。

:::note
再度エクスポートすると、同じ会話が別の名前で二重に書き出されることがあり、後続のスキルが同じ会話を二重に処理します。
再エクスポートの前には、対象のエージェントと月のサブツリー (例: `chatlogs/originalLogs/claude/2026/2026-06/`) だけを削除してください。
他のエージェントや他の月、分類済みのファイルを巻き込まないようにするためです。
:::

## 実行例

Claude の 2026 年 6 月分のセッションをエクスポートします。

```bash
/export-chatlogs claude 2026-06
```

ChatGPT のデータエクスポートを取り込みます。ChatGPT からダウンロードしたアーカイブを先に展開し、そのディレクトリを指定します。

```bash
/export-chatlogs chatgpt 2026-06 --input-dir ~/Downloads/chatgpt-export
```

完了すると、書き出し・スキップ・エラーの件数と出力先が報告されます。
次は [`/filter-chatlogs`](./filter-chatlogs) で不要なログを削除します。
